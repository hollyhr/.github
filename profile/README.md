# HollyHR

**Simple HR your growing team will love.**

HollyHR is modern HR software for small UK teams that want less administration
and a dependable people record. It brings together time off, who's away, people
records, documents and onboarding, with straightforward pricing and no card
required to start.

Ask Holly, the public API and hosted MCP are normal product capabilities, not
enterprise extras. Teams can use HollyHR directly, connect their existing
tools, or let an approved AI assistant work through the same governed HR
record.

## Build and automate with HollyHR

- A documented REST API with scoped keys, pagination, ETags and idempotent
  writes.
- An OpenAPI 3.1 contract and generated TypeScript client.
- A first-party hosted MCP server for permission-aware reads and
  confirmation-gated actions.
- Ask Holly for everyday questions and safe in-product HR tasks.
- Practical examples that start read-only and make sensitive boundaries
  explicit.

API and MCP reads are available on every plan. Standard and Plus include
governed writes. System Admins select every granted scope, and MCP mutations
retain human confirmation and HollyHR's emergency safety switch.

Connect the official [`hollyhr-mcp`](https://github.com/hollyhr/hollyhr-mcp)
server, start with
[`hollyhr-api-examples`](https://github.com/hollyhr/hollyhr-api-examples), or
inspect the
[`hollyhr-api-client`](https://github.com/hollyhr/hollyhr-api-client) source and
versioned OpenAPI contract. The full guides and API reference live in the
[developer documentation](https://developers.hollyhr.com).

## Public projects

- [`hollyhr-api-client`](https://github.com/hollyhr/hollyhr-api-client) -
  official TypeScript SDK source, tests, examples and versioned OpenAPI
  contract.
- [`hollyhr-mcp`](https://github.com/hollyhr/hollyhr-mcp) - official endpoint,
  setup, scopes and write-safety documentation for the hosted MCP server.
- [`hollyhr-api-examples`](https://github.com/hollyhr/hollyhr-api-examples) -
  runnable API, webhook and MCP examples.
- [`awesome-hr`](https://github.com/hollyhr/awesome-hr) - a carefully maintained
  collection of useful HR, employment and people-technology resources.

The HollyHR application itself is developed privately. Public repositories are
published when they are genuinely useful outside our own team and we can
maintain them properly.
