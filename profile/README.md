# HollyHR

**Simple HR your growing team will love.**

HollyHR is modern HR software for teams that want less administration and a
cleaner people record. It brings together time off, who's away, people records,
documents and onboarding, with straightforward pricing and no card required to
start.

[Website](https://www.hollyhr.com) ·

## Build with HollyHR

- A documented REST API with scoped keys, pagination, ETags and idempotent
  writes.
- An OpenAPI 3.1 contract and generated TypeScript client.
- Hosted MCP for permission-aware reads and confirmation-gated actions.
- Practical examples that start read-only and make sensitive boundaries
  explicit.

Start with [`hollyhr-api-examples`](https://github.com/hollyhr/hollyhr-api-examples)
or browse the full [developer documentation](https://developers.hollyhr.com).

## Public projects

- [`hollyhr-api-examples`](https://github.com/hollyhr/hollyhr-api-examples) —
  runnable API, webhook and MCP examples.
- [`awesome-hr`](https://github.com/hollyhr/awesome-hr) — a carefully maintained
  collection of useful HR, employment and people-technology resources.

The HollyHR application itself is developed privately. Public repositories are
published when they are genuinely useful outside our own team and we can
maintain them properly.
